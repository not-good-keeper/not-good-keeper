## Featured Projects

### [FactoryRunner — Autonomous Navigation with ROS 2](https://github.com/not-good-keeper/factoryrunner-nav2)

An autonomous factory navigation simulation using ROS 2 Jazzy, Nav2, Gazebo, and TurtleBot3.

- Multi-station navigation with keepout and speed-restricted zones
- Depth-camera obstacle detection and collision monitoring
- Navigation parameter optimization using Optuna
- Repeatable scenario-based performance evaluation

**Stack:** ROS 2, Nav2, Gazebo, C++, Python, Optuna

### [Compact ViT for Indian Sign Language](https://github.com/not-good-keeper/compact-vit-sign-language)

An efficient vision transformer pipeline for Indian Sign Language recognition, designed with wearable and edge deployment constraints in mind.

- Factorised compact Vision Transformer architecture
- Model quantization and deployment-oriented evaluation
- 3.89M parameters and 1.97 MiB INT4 model
- 85.9% top-1 accuracy on a 50-word session-disjoint benchmark

**Stack:** PyTorch, Vision Transformers, MediaPipe, Model Quantization

### [PUMA 560 — Learning-Based Inverse Kinematics](https://github.com/not-good-keeper/puma560-pathwise-ik)

Exploring trajectory-level inverse kinematics through learned candidate generation, iterative refinement, and dynamic programming.

- Set-prediction network for joint configuration candidates
- Learned refinement and Viterbi-based trajectory selection
- Comparison against analytical inverse kinematics
- Evaluation of solution feasibility, trajectory continuity, and runtime

**Stack:** Python, PyTorch, Robot Kinematics, Dynamic Programming

### [Surface Crack Segmentation](https://github.com/not-good-keeper/surface-crack-segmentation)

Lightweight semantic segmentation for industrial surface inspection.

- MobileNetV3-Small encoder with a compact U-Net decoder
- Pixel-level crack and scratch localization
- ONNX inference and FastAPI integration
- 1.43M-parameter model designed for efficient inference

**Stack:** PyTorch, OpenCV, ONNX, FastAPI

### [Distributed City Analytics — UVH-26](https://github.com/not-good-keeper/DS-City-Analytics)

A distributed analytics pipeline for large-scale urban traffic imagery.

- Viewpoint reconstruction across 26,646 CCTV frames
- Distributed analytics using Apache Spark
- Traffic composition, congestion, and spatial statistics
- Data visualization and analytical dashboards

**Stack:** Python, Apache Spark, Computer Vision, Data Analytics
